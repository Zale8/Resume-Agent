# src/ — 产品代码

> 本目录是 Resume Agent 的产品代码区，**可以进入 Git**。

## 用途

存放 Resume Agent 的程序代码、脚本、自动化逻辑。

## MVP v0.1 状态

**暂为空。** MVP 阶段所有能力由「Agent + Markdown 资产库 + 工作流规范」驱动，无需运行代码。

## 后续规划

| 版本 | 内容 |
|---|---|
| v0.2 | 简历组装脚本（Markdown → DOCX/PDF）、模板渲染器 |
| v1.0 | CLI 工具：`resume add` / `resume match <jd>` / `resume generate` |
| v2.0 | 网申自动化（当前明确不做） |

## 红线

- **禁止**在代码中硬编码任何用户真实个人信息（姓名、电话、邮箱、经历等）
- 产品代码只通过**读取本地简历库路径**的方式调用个人数据
- 简历库路径通过配置或参数传入，不写死在代码里
